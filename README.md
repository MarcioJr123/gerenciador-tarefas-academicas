# Gerenciador de Tarefas Acadêmicas

Aplicação web para gerenciamento e visualização de tarefas acadêmicas.

## Funcionalidades

* Busca de tarefas por título
* Filtro por status
* Filtro por prioridade
* Combinação dos filtros
* Ordenação por prazo
* Botão para limpar os filtros
* Contagem de tarefas exibidas
* Estados de carregamento, erro e lista vazia
* Dados carregados através de arquivo JSON usando Fetch API

## Tecnologias

* HTML5
* CSS3
* JavaScript
* JSON
* Fetch API
